NPLcode dual player executors

Each live stream now has two player actions:
1. NPL Player: opens the existing local player.html?src=... executor.
2. YoNoTV Player: opens https://yonotv.pages.dev/page?src=https://yonotv.pages.dev/LINK?id=IND2 (URL-encoded as a query parameter).

The YoNoTV executor ID defaults to IND2, matching the example supplied. To use a different ID for a specific match, add yonoLinkId to that match record in Firebase (for example: yonoLinkId: "IND3"). The legacy externalPlayerId field is also accepted.

The two executors are independent: the NPL Player uses the stream URL saved in the NPLcode match record, while the YoNoTV Player uses the configured YoNoTV resolver ID.

Deploy all project files to the same Vercel project. Keep detail.html and player.html in the project root.

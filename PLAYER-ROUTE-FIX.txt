NPLcode Player Route Fix

Root cause:
The match page used a relative player.html URL. On /match/{matchId}, that resolves to
/match/player.html. The generic Vercel /match/:id rewrite then treats "player" as a
Firebase match key, producing "No match record exists for ID: player".

Fixes:
1. Player links now use the absolute /player?src=... URL.
2. vercel.json explicitly routes /match/player and /match/player.html to /player.html
   before the generic /match/:id rewrite.
3. detail.html refuses to treat reserved page names such as player as match IDs.
4. Supports legacy /match/player/{matchId} links by reading the ID after player.

Deploy:
Upload the complete ZIP contents, including the updated vercel.json, detail.html,
player.html, api folder, and other existing project files. Redeploy on Vercel.
Do not upload only detail.html: the route rewrite is part of the fix.

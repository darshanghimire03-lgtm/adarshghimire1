NPLcode inline live player update

What changed:
- detail.html now shows a player directly on the match page.
- Stream buttons load the selected URL inside that player instead of opening a new tab.
- .m3u8 HLS URLs use hls.js (or native HLS where supported).
- Other HTTP(S) URLs are embedded in an iframe.
- An "Open stream separately" link is also provided.

Deployment:
1. Upload/deploy the project files to your Vercel project, keeping the existing folder structure.
2. Confirm the Firebase configuration in detail.html and admin.html contains your real Firebase apiKey and appId (the uploaded project currently has YOUR_API_KEY and YOUR_APP_ID placeholders).
3. Add stream URLs in the Admin page as before. HLS URLs should end in .m3u8; provider player pages can be entered as iframe/embed URLs.

Important limitations:
- A third-party site may block iframe embedding using X-Frame-Options or Content-Security-Policy. This cannot be bypassed from your website; use the provider's official embed URL or a stream you are authorized to embed.
- HLS playback may fail if the stream host does not allow browser CORS requests, requires unsupported authentication, or is offline.
- DRM-protected streams are not decrypted or bypassed. Use the broadcaster's authorized player/embed integration.

Basic Cell Calculations

+

Addition

Add numbers from different cells.

A1 = 25 · B1 = 15 → 40
Full Process
  1. Click the cell where you want the result.
  2. Press =.
  3. Click the first cell.
  4. Press +.
  5. Click the second cell.
  6. Press Enter.
25 + 15 = 40

Useful Keyboard Shortcuts

Alt + =

AutoSum

Full Process
  1. Click the empty cell below numbers.
  2. Press Alt + =.
  3. Excel selects nearby numbers.
  4. Press Enter.
Auto‑creates SUM formula.
Ctrl + D

Fill Down

Full Process
  1. Select the cell with formula.
  2. Select cells below.
  3. Press Ctrl + D.
Formula copied downward.
F4

Lock Cell Reference

Full Process
  1. Click a cell with a formula.
  2. Edit the formula.
  3. Select the cell reference.
  4. Press F4.
A1 → $A$1
Ctrl + ;

Insert Date

Full Process
  1. Click an empty cell.
  2. Press Ctrl + ;.
Today's date is inserted.
